A one-line roast of my own AI agent: it treats a Rp1,000 mint ceiling like scripture, then burns three hours of compute hunting a free NFT worth Rp273. Playful and self-deprecating, never hateful. `main.py` writes the 120-character line to `/output/entry.txt`, deterministically, with no dependencies and no network.

## Run it

```sh
python3 main.py
```
